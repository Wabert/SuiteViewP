# TN3270 decoder pipeline

`suiteview/mainframe_nav/tn3270.py` keeps socket I/O separate from protocol
decoding and screen mutation:

1. **`TelnetFrameDecoder`** consumes telnet IAC framing. It emits negotiation
   frames (`DO`, `WILL`, subnegotiation payloads) and complete 3270 records when
   `IAC EOR` is seen. Escaped `IAC IAC` bytes are preserved in the 3270 payload.
2. **`TN3270CommandDecoder`** classifies each record as a 3270 command and
   extracts the WCC/write payload where applicable.
3. **`ScreenApplier`** parses write data into `WriteOrder` dataclasses and
   mutates `Screen` through a handler table keyed by order byte.
4. **`TN3270Client`** owns sockets, replies to negotiation, dispatches decoded
   records, and sends outbound AID/read-modified byte streams.

## Telnet negotiation supported

- `DO TERMINAL-TYPE` → `WILL TERMINAL-TYPE`
- `SB TERMINAL-TYPE SEND` → terminal type `IBM-3278-2-E`
- `DO/WILL BINARY`
- `DO/WILL EOR`
- Basic `TN3270E` device-type and functions negotiation used by the existing
  client

## 3270 commands supported

Both standard and SNA/alternate command bytes are recognized where the previous
parser did:

| Command | Bytes | Behavior |
| --- | --- | --- |
| Write (W) | `0x01`, `0xF1` | Applies write orders without clearing |
| Erase/Write (EW) | `0x05`, `0xF5` | Clears the 24×80 screen, then applies write orders |
| Erase/Write Alternate (EWA) | `0x0D`, `0x7E` | Clears the screen, then applies write orders |
| Read Buffer (RB) | `0x02`, `0xF2` | No screen mutation |
| Read Modified (RM) | `0x06`, `0xF6` | No screen mutation |
| Write Structured Field (WSF) | `0x11`, `0xF3` | Handles Read Partition Query/Query List and sends a basic Query Reply |

## Write orders supported

| Order | Behavior |
| --- | --- |
| `SBA` | Sets the current buffer address |
| `SF` | Starts a field, stores the basic attribute, and records field metadata |
| `SFE` | Starts a field using the basic 3270 field-attribute pair (`0xC0`) when present |
| `SA` | Parsed and skipped |
| `MF` | Parsed and skipped |
| `IC` | Sets the screen cursor to the current address |
| `PT` | Parsed and skipped |
| `RA` | Repeats one EBCDIC character up to the target address |
| `EUA` | Writes blanks up to the target address |
| `GE` | Writes the escaped graphic character as the current EBCDIC translation |

Regular bytes are translated with the module EBCDIC table and written at the
current address. The parser still preserves the historical final-cursor rule:
after a write, the screen cursor is the final current address even if `IC`
appeared earlier in the stream.

## Known gaps

- No TN3270E response-request handling beyond the existing basic negotiation.
- `SA` extended attributes and `MF` modifications are recognized but not applied
  to the display model.
- `PT` does not search for the next unprotected field.
- Character-set coverage is limited to the module's EBCDIC table; unknown bytes
  translate to spaces.
- WSF support is limited to Read Partition Query/Query List replies.

Golden byte-stream coverage lives in `tests/test_tn3270_golden.py`.
